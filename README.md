# Deepfake voice detection system using neural vocoders	
•	Developed a Deepfake Voice Detection System using the RawNet2 deep learning model to identify AI-generated synthetic speech through neural vocoder artifacts. 
•	Implemented multi-task learning for real/fake voice classification and vocoder identification to improve detection accuracy and robustness.
•	Implemented multi-task learning for real/fake voice classification and vocoder identification to improve detection accuracy and robustness.
•	Tools Used: Python, Deep Learning, RawNet2, PyTorch, Audio Processing
