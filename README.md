# RawNet2-Inspired Voice Detection Demo

A small, runnable educational project showing a waveform-based audio classification pipeline.

## Important scope and honesty note
This repository is a **pipeline demonstration**, not a validated deepfake voice detector.
The included WAV files are artificially generated signal proxies. They are **not human speech**
and were **not generated by HiFi-GAN, MelGAN, WaveGlow, or another neural vocoder**.
The model is a compact **RawNet2-inspired** implementation, not an exact reproduction of
the published RawNet2 architecture. No real-world accuracy claim is made.

Do not describe this demo as trained/evaluated on a real/fake speech corpus. To build a
real detector, replace the demo files with properly licensed human speech and vocoder-
generated speech, split by source speaker/utterance, and evaluate on held-out vocoders.



## Setup (Windows / VS Code)
Use Python 3.10 or 3.11 if PyTorch installation is problematic on your Python version.

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```



## Git
The `.pth` file is generated by training and is not included. The WAV proxy examples are included
so the repository can be inspected and the training pipeline can run immediately.
